Written before any computation. Attacks each MR-2d weakness structurally.

|---|---|
| Scheme mismatch: NNLO-fit L_i used in a tree-NLO test | Use only **NLO-fit** L_i (BE14 Table 1 p⁴ fits; GL85) in a **one-loop** amplitude, so orders are consistent. BE14 NNLO is reported as a diagnostic only and not counted. |

| ≥2 independent non-NNLO sources | S1 = BE14 p⁴ NLO fits (2014). S2 = GL85 original estimates (1985), independent data era and analysis. |

## Method (fitness)
- Route: SU(3) L_i → SU(2) l_i^r(μ) via the one-loop GL85 matching, which includes the K and η loops as ν_K, ν_η:
  - l1 = 4L1+2L3−ν_K/24, l2 = 4L2−ν_K/12, l3 = −8L4−4L5+16L6+8L8−ν_η/18, l4 = 8L4+4L5−ν_K/2.
  - Sources: CITED from Gasser, Haefeli, Ivanov, Schmid 0706.0955 eq. (2) reproducing GL85. This matched my memory, which was checked before use.
- Then the SU(2) one-loop ππ amplitude in BCEGS form, using the one-loop b1..b4 (BCEGS hep-ph/9707291 App. B) and the exact loop functions (MR-2 script, already validated against CGL threshold values).
- Equivalence (to be proved in Lean): b1+b2+b3+b4 = 2l1+l2+2l3 + const + L-term (l4 cancels). With the matching this reduces to Z/2 + K/η logs, which is consistent with the MR-2d tree result.
- Error from the SU(3)→SU(2) expansion: O(Mπ²/MK²) ≈ 8% of the NLO part. The r_i^K terms (BCEGS) are O(p⁶) and dropped. Disclosed.
- Matching uses physical MK, Mη (strictly the m_ud → 0 values). This shift is absorbed into the same 8%.
- Is P clean? s = t = M², u = 2M² are all below 4M², so the loop functions are real and finite at P (check numerically).
