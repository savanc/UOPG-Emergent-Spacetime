## Verdict (plain language)

**CONDITIONAL** for the M3 primary dataset (BE14 NNLO preferred). On its quoted experimental errors alone, the
measured L3/L2 = −3.79 ± 0.31 lies **outside every unitary large-N tree theory** (needs L3/L2 ≥ −3) by 2.55σ
(Monte Carlo: P(inside) = 0.003). It comes back inside 2σ once any large-N_c correction band of at least **6.5 %** of
the value is allowed; with the pre-registered 30 % band the pull is only 0.67σ. A real-world (N_c = 3) number need not
obey a large-N bound, so the honest reading is: *the comparison is meaningful only after a 1/N_c band is admitted,
and once it is admitted the data cannot tell the M3b family's endpoints apart* (see "Discriminating power").

The NLO fit (BE14 p⁴, −2.38 ± 0.35) is **WELL-POSED**: it sits inside the M3b family interval [−3, −2].

## Discriminating power (not pre-registered; reported because it decides how M3b should be used)

The 30 % band on D1 is σ_N = 1.14, wider than the whole family interval (width 1; Lean `band_wider_than_family`).
With it, the two endpoints ε = 0 and ε = −1 differ by under 1σ_total. So even where the LEC-ratio test is
well-posed, it cannot measure ε usefully. D2 (σ = 0.35, no higher-order error) would separate them by ≈ 2.9σ, but it is
an NLO fit whose own NNLO shift is the D1–D2 difference (1.4, i.e. 4σ of D2's error). The LEC ratio is a poor M3b
target.

## Correction to the ladder review (process finding)

The ladder review and the M3 addendum say that "no unitary large-N tree completion could pass this comparison" and
that "VMD/Skyrme (−3) fails the same comparison". **That is wrong under M3's own pre-registered rule.** M3 put the
±30 % band on the *theory* value. For the vector edge r = −3, the band [−3.9, −2.1] meets I₁ = [−4.10, −3.48], so
VMD would **PASS** (Lean `vmd_edge_passes_m3_rule`). The M3 FAIL of the hidden-zero value (band [−2.6, −1.4] vs
I₂ = [−4.41, −3.17]) stands and is unchanged. But the evidence against hidden zeros in M3 is not "weak because
everything fails". It is a genuine discrimination: under the M3 rule, ρ dominance passes and the hidden zero fails.
The real well-posedness issue is the one above. The *unbanded* data point is outside R_full, so any test that allows
no 1/N_c band (like the D1 row here with z_exp) is ill-posed. MISSION.md, the M3 review addendum and the ladder
review get a dated correction note (the wording is changed in MISSION.md only).
