# MR-4b prereg — third πK source: Peláez–Rodas 2020 (arXiv:2010.11222, Phys. Rep.) — 2026-10-13
Committed and pushed before any value in their Table `tab:stparameters` was read. The structure was read through a digit mask.
- **Conventions (CITED, digits of the formula only):** F⁺ = Σ C⁺_ij (t/mπ⁺²)^i (ν/(4mπ⁺mK))^{2j}, F⁻ = (ν/(4mπ⁺mK)) Σ C⁻_ij …, with ν = s − u. These are identical to BDM's (BDM ν/mπ = (s−u)/(4mK mπ)), so `sims/mr4/mr4_verdict.py` applies unchanged. F^{3/2} = F⁺ − F⁻ (same isospin convention assumed; checked in the result via their isospin definitions).
- **Rows available:** C⁺00, C⁺10, C⁺01, C⁺11, C⁻00, C⁻10, C⁻01. Missing C⁺20, C⁺30, C⁻20, C⁺02 are set to 0, exactly as for Lang–Porod. No tuning.
- **Primary column:** "This work, Fixed-t" sum rules with CFD input. The HDR column is a reported variant, and where HDR says "like fixed-t" the fixed-t value is used. The NNLO-ChPT column (Bijnens et al.) is not counted, since it is not dispersive.
- **Metrics and band identical to the MR-4 prereg (37820ee):** r, r0, r1 with box τ ∈ [0,4], ν/mπ ∈ [−1,1]. PASS iff each of r, r0, r1 − 2σ ≤ 1/3. Null: random lines, f ≤ 0.3 for discrimination. MC over quoted errors, uncorrelated.
- **Full +1 rule (pre-declared):** MR-4 qualifies for full +1 if S3 PASSes with f ≤ 0.3. If S3 FAILs, MR-4 is 2 of 3 sources and **recommended downgrade to +0.25** (the author decides). An S3 PASS with f > 0.3 means no change (+0.5).
