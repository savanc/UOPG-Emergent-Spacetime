### Gate 1 (theory): well-posed but not independent → FAIL
- Algebra [PROVED, Lean `PositiveGeometryEmergentSpaceTime.SubthresholdGate`, 4 theorems, 0 sorry, axioms propext/Classical.choice/Quot.sound]. Units M²=1, x=M²/F²:
  - `Asub_at_P`: A(P) = x(α−β)/3 + x²(λ1+λ2) − x³(λ3+λ4).
  - `zero_iff`: the zero holds iff α−β = −3x(λ1+λ2) + 3x²(λ3+λ4).
  - `lo_trivial`: at LO (α=β=1, λi=0) the zero holds automatically, so all content starts at O(p⁴), as in MR-2.
  - `nontrivial`: the relation is not a kinematic identity.
- Well-posedness: OK. P sits inside the Mandelstam triangle at distance M²/3 from the expansion centre, and the polynomial truncation error is O(p⁸).
- Is it a pure ChPT identity? No. At O(p⁴), α−β depends on ℓ̄3, ℓ̄4 and λ1, λ2 on ℓ̄1, ℓ̄2, so the condition is a LEC relation. That is exactly MR-2's `poly_zero_iff` second condition.
- **Independence: FAIL.** The subthreshold parameters are a re-parametrisation of the same two-loop amplitude. CGL derive α…λ4 from the same Roy solution and the same b̄i that MR-2 already scored (S1 = CGL). So A(P) from the subthreshold parameters is MR-2's own observable, Z, written in different coordinates. Up to the truncation (difference O(p⁸)) it gives the same number. Scoring it would count MR-2 twice.
- A GKPY-type tabulation would be a different dataset for the same observable. At most it is a third-source firm-up of MR-2, which is already non-blind. It does not earn a new observable.
