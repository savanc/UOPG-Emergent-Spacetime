## Theory (Gate 1)
- **CONJECTURE (unequal-mass spurion hidden zero):** the single-trace ordered amplitude A[π⁺π⁻K⁺K⁻] is the only single trace in π⁺K⁺ → π⁺K⁺ (I = 3/2). Its non-planar pair is (π⁺, K⁺), with c̃₁₃ ∝ p_π·p_K = 0. Equivalently the zero line is **s = Σ ≡ Mπ² + MK²**, the unequal-mass generalisation of u = 2M² (MR-2: p1·p3 = 0).
- **SIMULATED** (`sims/mr4/pik.py`, brute-force GL85 Lagrangian, physical masses, Z-factors):
  - LO F^{3/2} ∝ (Σ − s). It vanishes on the whole line.
  - NLO tree on the line ∝ c0 + c1 t + c2 t², with
    - c2 = 2L1 + L2 + L3 (the massless/M3 combination, so not independent of M3);
    - c1 = −(4L1+L3)(MK²+Mπ²) + 2L4(MK²+Mπ²) − 2L5(MK²−Mπ²);
    - c0 = 2Mπ²[(4L1+L3−4L4+4L6+2L8)MK² − L5 Mπ²].
  - ChPT does not force these to vanish, so the test is non-trivial.
- **Gate 4 avoided:** we test the data amplitude directly on the line, so no LEC values are needed.

## Observable (CITED conventions, BDM)
- F^{3/2} = F⁺ − F⁻. F⁺ = Σ C⁺_ij τ^i (ν/mπ)^{2j}; F⁻ = (ν/mπ) Σ C⁻_ij τ^i (ν/mπ)^{2j}; τ = t/mπ², ν = (s−u)/(4mK).
- On the line, ν/mπ = κτ with κ = mπ/(4mK). Here mπ = mπ⁺ = 139.57, mK = 495.7 (memory, BDM's own mK is used if stated).
- Line function g(τ) = g0 + g1 τ + g2 τ² + g3 τ³:
  - g0 = C⁺00
  - g1 = C⁺10 − κC⁻00
  - g2 = C⁺20 + κ²C⁺01 − κC⁻10
  - g3 = C⁺30 + κ²C⁺11 − κC⁻20 − κ³C⁻01
- **r = RMS_{τ∈[0,4]} g / RMS_{box} F^{3/2}**, box = τ ∈ [0,4], ν/mπ ∈ [−1,1] (same polynomial truncation).
- Primary: r, plus g0 and g1 separately normalised by the box RMS (r0 = |g0|/S, r1 = 4|g1|/S). g2 is reported and flagged as M3-correlated.

## Rules
- **PASS** if r + 0·σ ≤ 1/3 is consistent within 2σ (r − 2σ_r ≤ 1/3) **and** r0, r1 each ≤ 1/3 within 2σ, for S1 = BDM Roy–Steiner and S2 = Lang–Porod 1978 (BDM table column; missing coefficients → only the g0, g1 test and a truncated r).
  - One source passes → INCONCLUSIVE. None → FAIL.
- σ: MC over quoted errors, uncorrelated (no covariance published, disclosed).
- **Null:** random lines ν/mπ = a + bτ, a ∈ U[−1,1], b ∈ U[−0.5,0.5], same r definition. f = fraction with r ≤ 1/3. Counts as discriminating if f ≤ 0.3.
- **Blind:** I have no reliable memory of the πK C_ij values (disclosed: none recalled). A PASS with f ≤ 0.3 in both sources counts +1 blind for OP-2 (pending the author); a PASS with f > 0.3 counts as weak.
