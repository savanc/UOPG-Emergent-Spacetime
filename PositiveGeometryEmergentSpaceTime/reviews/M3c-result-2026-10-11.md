# M3c result: can the Coon q-deformation move ε toward ρ?

Date: 2026-10-11 (Europe/London). Pre-registration: `prereg/M3c-coon-2026-10-11.md` (commit fba2bb8, pushed before
computing). Scripts: `scripts/m3c_coon.py` (outputs `m3c_eps_output.txt`, `m3c_pw_output.txt`,
`m3c_pw_near1_output.txt`, `m3c_eps.json`). Lean: `lean/PositiveGeometryEmergentSpaceTime/Coon.lean`. No pion data were used.

## Verdict (plain language)

**WRONG-SIDE** for the pre-registered primary family. The Coon deformation that keeps the pion's Adler zero
(α0 = [1/2]_q) moves ε **away** from ρ dominance, toward scalars (ε > 0, up to ≈ 0.40 where unitarity was checked), and stays unitary on our
grid. This is not a numerical accident. Lean proves that for *any* symmetric prefactor, the q-deformed zero curve
bends the "scalar" way, so ε > 0 whenever g1,0, g2,0 > 0. The FPRS version (α0 = 1/2, which has a constant term and
no Adler zero) does move ε toward ρ, but only to **ε ≈ −0.023**, about 2 % of the way to ρ dominance. So: **the
Coon q-deformation cannot reach the ρ side in any useful amount. M3b stays a fit (a measurement of ε), not a
geometric prediction.**

## Why: the zero-curve lemma (the structural result)

For any amplitude with an Adler zero and g1,0 ≠ 0, the zero set near the origin is a curve u = −s + k s² + … .
Expanding the jet on it gives **ε = −k g1,0/(2 g2,0)** (Lean `jet_on_curve`, `eps_of_curvature`, `eps_pos_iff`).
- The hidden zero is k = 0, so ε = 0.
- ρ dominance needs k > 0.
- Scalars correspond to k < 0.

In F_B the n = 0 factor is exactly στ − q = −c(r(s+u) − c su), with r = √q, c = 1 − q (`stau_sub_q`). Its zero curve
has k = −c/r < 0 for every q < 1. The rest of the amplitude, *whatever its symmetric prefactor* (C = 1 or FPRS's
polynomial-residue C), only rescales the jet (`jetB`, `epsB`). Hence ε = c g1,0/(2r g2,0) > 0 (`epsB_pos`). So the
tertiary variant is answered structurally: same sign.

To reach ρ dominance, a deformation would need an Adler zero whose zero curve bends the other way. The Coon
deformation's curve bends the wrong way.

## What this means for M3b (recommendation)

**Run M3b as pre-registered (a measurement of ε from g̃ρ²), unchanged. Do not replace it with a geometric
q-version.**
1. The Adler-compatible Coon cannot reach ε < 0 (proved, given positive g1,0, g2,0).
2. The Adler-violating FPRS Coon reaches only |ε| ≤ 0.023 ≪ 0.5.
3. In the prior-art plot (FPRS Fig. 3), the scalar-subtracted Coon moves ρ-ward, but that comes from removing
   scalars by hand. Scalar-less LS is already at ε ≈ −0.86 (FPRS eq. 113), and q moves it *back* toward the su-model
   kink ε ≈ −0.63 (FPRS eq. 46, 3.26/2 = 1.63).

Either way the ρ-ward motion is not produced by q. The honest statement for the mission is that within the Coon
deformations, **nothing geometric produces ρ dominance**; ε ≠ 0 at O(p⁴) needs a non-geometric input (scalar removal,
or an explicit ρ-exchange component, as in M3b's chord). Also **is q fixed?** No: q is a free dial in every version
(Maldacena–Remmen's AdS reading would tie it to a background, which is conjectural and not part of our chain).

## Concerns

1. **Unitarity is checked only on a finite set.** Pole residues for n ≤ 6 and J ≤ 12 in D = 4 on a q grid; no proof.
   The accumulation point is not checked (Jepsen found cut-positivity violations for the polynomial-residue
   Veneziano-type Coon; C = 1 has no cut, but infinitely many spins per level).
2. **Coon is a 4-point object only.** No consistent N-point Coon exists for q < 1 (Geiser 2311.04130), so this is not
   a deformation of our curve-integral/associahedron completion at n ≥ 5. "Geometric" here means only the q-string
   reading (Li–Sun 2307.13117, Maldacena–Remmen).
3. **ε here comes from Taylor coefficients.** It equals the spectral ε of M3b only if the dispersion relation holds
   with k_min = 1 (FPRS state it does for C = 1). We did not cross-check with a spectral sum.
4. **The pre-registration disclosed a first-order hand expansion** that predicted F_B's sign. The result confirmed it.
   The test was therefore not blind on direction, only on magnitude and unitarity.
5. **The choice α0 = [1/2]_q is ours.** It is the unique intercept that makes the n = 0 zero pass through the
   origin. Other Adler-compatible q-deformations (e.g. Cheung–Remmen's q-hypergeometric family with an r
   parameter) were not scanned. The zero-curve lemma says what any of them would need (k > 0).
