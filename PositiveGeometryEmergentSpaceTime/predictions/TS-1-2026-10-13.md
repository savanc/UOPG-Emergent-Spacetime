# TS-1 — time-stamped blind predictions for future measurements (registered 2026-10-13)

**Status:** REGISTERED. Nothing is scored yet and no credit is claimed. The registration time is the git commit time plus the push to the private research repository. The SHA256 of this file is recorded in the commit message.
**Blindness protocol:** no target value was read while writing this file. A target counts only if the scoring source is **released after this commit**, or was demonstrably not read before it. Recalled values are disclosed per target (§0).
**Tags:** PROVED = Lean in `lean/PositiveGeometryEmergentSpaceTime/*`; SIMULATED = code in this repo; CITED = earlier repo reviews; CONJECTURE = assumption not derived.
**Machinery:** Lovelace–Shapiro (LS) residues (`reviews/MR-1b-result-2026-10-12.md`, `PositiveGeometryEmergentSpaceTime.LSResidue`), the massive ππ hidden zero at P (`reviews/MR-2-result-2026-10-12.md`, `PositiveGeometryEmergentSpaceTime.MassiveZero`), and the πK line s = M_π² + M_K² (`reviews/MR-4-result-2026-10-13.md`, `PositiveGeometryEmergentSpaceTime.PiKZero`).

## 0. Memory disclosure
- Physical-point PDG ρ3(1690) and f4(2050) masses, widths and BRs are **known**, from MR-1b. Physical-point data are therefore excluded from TS1-1 and TS1-2.
- ρ5(2350): only the mass and the fact that PDG has no ππ BR, from the MR-1e gate. No coupling is known.
- f6(2510): I have a **vague recollection** of a single GAMS-era Γ(ππ)/Γ of a few percent (≈ 6 %, unreliable). TS1-4 is therefore **capped at 0.25**, and any existing GAMS/BINON value is excluded from scoring.
- Lattice heavy-m_π spectra and couplings (ρ3, f2, f4, ρ g), the πK subthreshold amplitudes and the ππ all-isospin amplitudes at unphysical masses: none recalled. The rethink saw one search snippet saying "g_ρππ weakly m_π-dependent" (Yu et al. 2311.03903). It does not touch any target here.
- LS leading-trajectory mass ratios: the physical ones are known (non-blind). Lattice heavy-mass values are not recalled.

## 1. Declared inputs (counting rule, MISSION.md)
- **Per sector:** one free unit, **m_ρ**, on each ensemble or experiment.
- **Extra inputs:** M_π and M_K (per ensemble), f_π only where an amplitude normalisation needs it, and the LS intercept choice α₀ = ½ with r = m_f2²/m_ρ² = 3 [CONJECTURE: the LS model choice, fixed before any data].
- **Extra input count:** 1 for the LS family (M_π, which only enters phase space) and 2 for the zero lines (M_π, M_K). Each family registers more predictions than extra inputs.

## 3. Null rules (fixed now)
- **TS1-1 to TS1-4:** null = log-uniform ratio on [0.02, 1]. f = the fraction landing inside the band. A PASS is discriminating only if f ≤ 0.3. Otherwise it is "consistent, not informative" and earns 0.
- **TS1-5:** null = uniform m²/m_ρ² ratio on [1, 2×prediction]. The same f ≤ 0.3 rule applies.
- **TS1-6:** the MR-4 null, i.e. random lines ν/M_π = a + bτ, a ∈ U[−1,1], b ∈ U[−0.5,0.5]. Across N ensembles, f compounds as ∏ f_i.
- **TS1-7:** the MR-2 null, i.e. random triangle points with f = frac(|R|/S ≤ 1/3).

## 5. Scoring rule
1. Score only on sources whose first public version (arXiv timestamp) is **after** this commit. For TS1-6 and TS1-7, also exclude any ensemble read by LAT-2 before its own prereg.
2. **PASS** for a family needs a pass on ≥ 2 independent groups. One group passing = INCONCLUSIVE. Any band violation at > 2σ in a well-posed source = FAIL for that target.
3. **Well-posedness gate** (checked on structure, digits masked, before reading): the state is resonant with Γ/m < 0.3, the coupling error is < 30 %, and the masses are given per ensemble. Otherwise the source is skipped, not failed.
4. **Credit:** at most the column "Max credit". The total TS-1 contribution to OP-2 is capped at 0.5 until the author rules, because the machinery is the same as MR-1b, MR-2 and MR-4. Credit is decided only by the author.
5. **No retuning:** bands, nulls, α₀ and r are frozen by this commit. Any later change is a new registration with a new hash.
