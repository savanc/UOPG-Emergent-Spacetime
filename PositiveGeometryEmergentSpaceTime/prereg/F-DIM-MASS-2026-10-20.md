## Model and criterion
- Trunk amplitude (`PositiveGeometryEmergentSpaceTime.LSResidue`, Lovelace–Shapiro): A = Γ(1−α(s))Γ(1−α(t))/Γ(1−α(s)−α(t)) with α(s) = α₀ + α′s.
- The **LS amplitude is a model**. A gate conflict below means **the trunk model fails at physical m_π**, not that physics fails.
- Unitarity criterion, the same as F-DIM′: one global sign σ with σ·c_{N,j}(D) ≥ 0 for all levels N and spins j, using SO(D−1) Gegenbauer coefficients (AEHM 2201.11575). It is checked at **D = 4 for N ≤ 40** (exact rationals), with a D-scan 3..40 for N ≤ 12 as report only.
- External mass² in α′ units is m² = α′m_π².

## α₀ formulas (all with α(m_ρ²) = 1; α′ in GeV⁻²; masses in GeV or MeV, with consistent units)
- **P_a, baseline (trunk as defined, Bianchi–Consoli–Di Vecchia eq. (2.4)):** the Adler zero sits at s = t = m_π², i.e. 2α(m_π²) = 1. This gives α′ = 1/(2(m_ρ² − m_π²)) and α₀ = 1 − α′m_ρ² = ½ − α′m_π².
- **D_c threshold:** level-1 spin-0 positivity requires k²/(D−1) + (α₀−k)(α₀+1−k) ≥ 0, with k = (2 − α₀ − 4m²)/2. On the P_a line this reduces to D ≤ D_c(α₀) = 2(1+4α₀)/(2−α₀). D = 4 passes iff D_c ≥ 4, iff α₀ ≥ ½, iff m_π = 0.

## Candidate zero-parameter fixes, declared in advance: 5 (trials = 5)
| # | Fix | Definition | Fitted numbers |
|---|---|---|---|
| P_b | Adler point moved to s = t = 0 | α₀ = ½, α′ = 1/(2m_ρ²) | 0 |
| P_c | Adler point at the symmetric point s = t = u = 4m_π²/3 | α′ = 1/(2(m_ρ² − 4m_π²/3)), α₀ = 1 − α′m_ρ² | 0 |
| F5 | Trajectory from ρ and f₂, no Adler input | α′ = 1/(m_f2² − m_ρ²), α₀ = 1 − α′m_ρ² | 0 (uses measured m_f2) |
| F6 | Daughter shift Γ(λ−α) with λ ≠ 1 | needs λ | ≥1 → **AUTO-FAIL** |
| F7 | Coon q-deformation | needs q | ≥1 → **AUTO-FAIL** |

**Pass rule for each fix:** (i) zero fitted numbers, AND (ii) positive at D = 4 for all N ≤ 40 with **both** S1 and S2.

**Cost tag:** the only LS zero line that coincides with the established leading-order current-algebra (Weinberg) zero line s + t = 2m_π² is P_a. This is an analytic fact: the LS zero set α(s) + α(t) = 1 is the line s + t = (1−2α₀)/α′, and it equals s + t = 2m_π² iff α₀ = ½ − α′m_π². So any passing fix other than P_a is a repair **at the cost of** the LO Adler-zero location.

## Verdict set (exhaustive)
- Baseline P_a not positive at D = 4 (in S1 or S2):
  - and a fix that keeps the Weinberg line passes → **GATE-FAIL-REPAIRED** (impossible by the cost analysis, listed for completeness);
  - and some other fix passes → **GATE-FAIL-REPAIRED-AT-COST (names)**;

- Otherwise → **UNCLASSIFIED**.
