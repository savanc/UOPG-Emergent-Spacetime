"R4-DM v3, full protocol"). `AUTORESEARCH-STOP` stays on origin/main. Pushed ALONE (this prereg + locked checker

## 0. Re-read: R4-DM v2 (prereg af4430e, result e76283d, reviews/R4-DM2-result-2026-10-20.md) and the notation audit
v2 locked output 1/89 (`EWZ1b.forced` only DERIVED; meter_Q 0/73, meter_C 1/16). Two gaps
(notes/NOTATION-AUDIT-2026-10-20.md H3):
- **Normalisation blindness.** v2's smuggling test (c) knew only the Q = T₃ + Y, yQ = 1/6 *fractions*. The Lean also
  uses the integer ×6 form (STRUCT1b:34-38 charges 1, −4, 2, −3, 6; X6:82 yQ = 1; STRUCT2:54), the N_c-symbolic form
  yQ = 1/(2N_c) (FRMU:57), and a Y vs Y/2 convention (Q = T₃ + Y/2 adds 4/3). An SM charge typed into a hypothesis in
  any of these forms, next to a geometry constant, would have read DERIVED under v2.
- **D1 too wide.** v2's D1 made every binder `x : BR5p.Inv` an SM variable, so a conclusion that merely mentions `x`
  counted as SM-structure. This added `BR5p.dot4_explicit` (NON-CONSTRAINING) and `BR5p.built_zero_of_gauge`
  (SMUGGLED) to the denominator: 89 instead of the 87 of v1 and of v2's own prediction.
**v2 is superseded, not edited.** The v2 live output is known to the author of this prereg (disclosed: the
predictions below are informed by it and by reading the hypotheses of v2's 21 non-NO-GEOMETRY rows in
`graph/r4dm2_decls.jsonl`; the point of v3 is that the new rules catch the planted smuggles without moving the live
number except for the two D1 rows).

## 1. What changes (and nothing else)
Rule, verdict order (AUTO → WITNESS → NO-GEOMETRY → SMUGGLED (a)–(d) → SM-INPUT-FED → NON-CONSTRAINING → DERIVED),
SM vocabulary, manual list, witness list and all 97 library-module classes are v2's (`sims/r4dm3/classification.json`
= v2 table + v3 planted entries + new keys `sm_literals_hyp_E1`, `sm_int_literals_hyp`, `nc_vars`, `charge_vars`,
`v3_rules`). D1–D3 kept. New switches in `FIXES`:
- **E1 charge-normalisation literals.** Test (c) also fires on a hypothesis that (i) contains the Y/2 fraction 4/3
  (1/3, 2/3, 1/2 were already listed), or (ii) references a **tier-Q** SM variable and contains a standalone integer
  literal n with |n| ∈ {3, 4, 6} (the distinctive values of the integer ×6 form, 1/−4/2/−3/6/3, and of the integer Y/2
  form). Standalone = not part of a fraction, not an exponent, not glued to an identifier. **Tier-C variables are
  exempt**, because `EWZ1b.forced`'s hypotheses carry kinematic integers (−3, 4, −4, …) on the couplings a, lam3, lam4;
  without the exemption E1 would wrongly flag it. (Known from the v2 output; disclosed.) Limitation: 1 and 2 are not
  flagged (too generic), so an integer-form smuggle of only yQ = 1 or yd = 2 is not caught by E1.
- **E2 N_c-symbolic normalisation.** Test (c) also fires on a hypothesis in which a single multiplicative term contains
  both an `nc_vars` variable (N_c, Nc) and a `charge_vars` variable (yQ yu yd yL ye yn yH Qu Qd qi qj lam lam'), e.g.
  2·N_c·yQ or N_c·yQ, or which divides by an `nc_vars` variable (1/(2N_c), 1/N_c).
- **E3 D1 tightened.** A bound SM-structure binder (`x : BR5p.Inv`) puts the statement in the denominator only if the
  conclusion reads a coupling/charge field (an SM-var constant such as `x.a`, `x.lam3`, `x.lam4`). A conclusion that
  only mentions `x` (kinematic reads, or `x` passed whole) is not SM-structure. D1's unconstrained-identity rule is
  unchanged.
- Live export: `sims/r4dm3/R4DM3Export.lean`, export block byte-identical to v1 `sims/r4dm/R4DMExport.lean`
  (the guard checks the v1 exporter, the v3 exporter and the v3 planted file blocks are identical), output
  `graph/r4dm3_decls.jsonl`. It should be identical to `graph/r4dm2_decls.jsonl` (library Lean unchanged since
  e76283d; checked and reported).
