## 1. Question
F-DIM-MASS found that the only zero-parameter fix restoring D = 4 unitarity of the LS pion amplitude at physical m_π
is P_b: α₀ = ½, Adler zero moved from s = t = m² to s = t = 0, off the LO current-algebra line (`FDimMass.weinberg_line_iff`).

Does the data on S-wave ππ scattering lengths make that cost visible? More precisely, does P_b beat, match or do worse than Weinberg's LO prediction?

## 3. Exact formula (fixed; the checker implements exactly this)
- A(s,t,u) = λ [V(s,t) + V(s,u) − V(t,u)] (Lovelace 1968), where
  - V(s,t) = Γ(1−α(s)) Γ(1−α(t)) / Γ(1−α(s)−α(t));
  - α(s) = α₀ + α′s.
- Isospin amplitudes:
  - T⁰ = 3A(s,t,u) + A(t,s,u) + A(u,t,s);
  - T² = A(t,s,u) + A(u,t,s);
  - a₀^I = T^I(4m², 0, 0)/(32π), dimensionless (m_π units).
- Trajectories (fixed in F-DIM-MASS):
  - **P_a** (trunk baseline): α′ = 1/(2(m_ρ² − m_π²)), α₀ = 1 − α′m_ρ²;
  - **P_b** (repair): α₀ = ½, α′ = 1/(2m_ρ²).
- **Normalisation N1, the only one; no alternatives tried.**
  - λ = −1/(2π α′ F²), where F = f_π/√2 is the physical pion decay constant (≈ 9×10¹ MeV, masked).
  - Origin: near α = ½, V(s,t) ≈ Γ(½)²(1 − α(s) − α(t)) = π(…). With the Adler line this gives A ≈ (s − m²)/F², i.e. Weinberg at linear order (Lean `FScatLen.ls_soft_normalisation`).
  - λ is fixed by F_π and α′ only, with **no fit**. Other normalisations (ρ width / KSRF, residue matching) are NOT used, and no trial count is spent on them.
- **Rival R_LO** (Weinberg 1966): A = (s − m²)/F², with the same m_π and F inputs and the same error treatment.
  - a₀⁰ = 7m²/(32πF²), a₀² = −2m²/(32πF²) (Lean `FScatLen.lin_weinberg_T0/T2`).
- **Rival R_CGL** (two-loop ChPT + Roy; Colangelo–Gasser–Leutwyler, NPB 603 (2001) 125). Fixed literature values (a₀⁰, a₀² and their errors), cited from 2 sources:
  - the CGL paper / abstract;
  - one independent quotation (NA48/2 paper or a review).
  - Context only; not part of the verdict rule.
