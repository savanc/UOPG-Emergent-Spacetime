R4 (`sims/r4/r4_separation.py`, prereg 2026-10-15) asks "is there a Lean edge from a STRUCT module to a non-STRUCT

proved inside a "geometry" module, and (d) cannot see SM data passed in as a hypothesis. R4-DM replaces it as the
geometry→SM measure. **R4 is superseded, not edited**; its locked file and results stay as written.

## 2. Definitions (the rule)
- **SM-structure statement S(d):** a theorem whose conclusion uses an SM-INPUT-role constant, or references a binder in
  the SM vocabulary, or uses an SM-var constant, or is on the manual list. (Conclusion *literals* do not make S: geometry
  statements legitimately contain numbers such as SC-2's 1/6.) Tier **Q** (quantum numbers, groups, ACC, N_c, N_gen,
  chirality) if any Q symbol, else **C** (coupling relations).
- **Verdict order** (closure = transitive PositiveGeometryEmergentSpaceTime type+value uses, auxiliaries looked through, from the new export):
  1. WITNESS (declared list). 2. **NO-GEOMETRY**: closure has no GEOMETRY-role def/inductive/ctor.
  3. **SMUGGLED** if any Prop hypothesis (a) uses an SM-INPUT constant, (b) constrains SM vars / SM-var constants with no
     GEOMETRY constant in it, (c) contains an SM literal (±1/6, ±1/3, ±2/3, ±1/2), or (d) equals the conclusion or a
     top-level conjunct of it.
  4. **SM-INPUT-FED**: the proof (value closure minus statement closure) uses an SM-INPUT theorem or definition.
  5. **NON-CONSTRAINING**: no SM symbol at all in the statement (manual-list items: a bare number matching an SM number
     is numerology, never DERIVED), or SM data universally quantified and unconstrained by any hypothesis with no
     SM-INPUT constant in the conclusion (identities, blindness results).
  6. otherwise **DERIVED**, flagged CONDITIONAL (has Prop hypotheses — a geometric/amplitude property is assumed) or
     UNCONDITIONAL, and source PG (closure contains a GEOMETRY-PG def) or AMP.
- **meter = #DERIVED / #S**, also reported as meter_Q, meter_C, and the DERIVED lists by source and condition.
- **Limitation (declared):** def roles are by hand; a GEOMETRY def that hard-codes SM numbers would be miscounted. Every
  DERIVED item is therefore hand-read in the result (B1/B2).
