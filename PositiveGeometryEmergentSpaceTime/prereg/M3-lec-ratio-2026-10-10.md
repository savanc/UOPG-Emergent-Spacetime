## Disclosure (post-hoc risk), stated first

This is the first rung that could be a prediction, so the following must be on record **before** the test:

1. **The prediction is already known to me analytically, and it is already published** (see §0). While reading
   the prior art I saw that every completion in our chain makes the ordered 4-point amplitude carry an overall
   factor (X13 + X24), i.e. the 4-point **hidden zero** at t = 0 survives to all orders. Then the O(p⁴) part is
   ∝ (s+u)², which fixes g2,1 = g2,0, hence L3 = −2L2 (with 2L1 = L2 from large N_c), ℓ1 = −ℓ2/2. This one-line
   argument was done by hand; it is written down here as the prediction. No script or CAS has been run.
2. **I have already seen the data.** While sweeping I opened Bijnens–Ecker 2014 (Tables 1 and 3), CGL 2001 (eq. 14.1)
   and Albert–Rastelli 2022 (Table 1, Fig. 9, which shows real-world points clustering near the Skyrme line
   g̃2′ = 4g̃2, i.e. far from the hidden-zero line g̃2′ = 2g̃2). From BE14 Table 3 by eye, L3/L2 ≈ −3.8 (NNLO,
   preferred fit), and from Table 1 ≈ −2.4 (p⁴ fit). **So I expect the primary test to FAIL**, and I know the
   p⁴-fit comparison would look better. The primary dataset below is therefore fixed by a rule that does not depend
   on which way it comes out: *the fit its authors designate as preferred* (BE14, Table 3). The p⁴ fit is secondary
   and **cannot change the verdict**.
3. What the pre-registration still buys: the target, the scale, the tolerance and the PASS/FAIL/INCONCLUSIVE rule are
   fixed now, before the exact propagation, and will not be moved.

## 0. Prior art (rung protocol, step 1). Swept 2026-10-10 before writing this file

Opened and read (PDF text, relevant sections):

  α′X_e,e → α′(X_e,e+δ), α′X_o,o → α′(X_o,o−δ), the unique c-preserving shift (§7.1), so **all hidden zeros persist

  (7.11) I₄ → α′Γ(−α′δ)Γ(α′δ)(X13+X24), "NLSM with λ² = α′Γ(−α′δ)Γ(α′δ)". The completion is a **one-parameter
  family** in a = α′δ ∈ (0,1) and "manifestly not cyclically symmetric", with cyclicity restored only at leading
  order. No O(p⁴) coefficients or LECs are discussed. [CITED]
- **Lovelace–Shapiro (LS)** as written in Albert–Rastelli (2.22): M_LS(s,u) = −Γ(1/2−α′s)Γ(1/2−α′u)/Γ(−α′(s+u)).
  The intercept 1/2 is fixed by the Adler zero; α′ = 1/(2m_ρ²). **Bianchi–Consoli–Di Vecchia arXiv:2002.05419**:
  N-pion extension from the NS string with massless pions; the 4-point is LS; Adler zeros; NLSM at α′ → 0; no LECs
  computed. [CITED]
- **Polyakov & Vereshagin, hep-ph/9509259 (PRD 54, 1112 (1996))**, §IV eqs. (4.1)–(4.6): the LS low-energy
  expansion gives **L2 = 2L1 (4.4), L3 = −2L2 (4.5), L2 = F0² ln2/(8m_ρ²) ≈ 1.25·10⁻³ (4.6)**. They note (4.4) is the
  large-N_c relation; (4.5) "is exactly the relation predicted by integration of the non-topological chiral anomaly"
  (chiral-quark-model) and "holds with any type of satellites added to a simple Lovelace–Shapiro amplitude"; their
  footnote 4 calls for a direct fit of 2L2 + L3. **So the primary prediction of this rung is published (1996).** [CITED]
- **Bartsch, Brown, Kampf, Oktem, Paranjape, Trnka, arXiv:2403.10594** (*Hidden amplitude zeros from double copy*):
  at O(p⁴) "there are two independent operators in the chiral Lagrangian. Both generate amplitudes with the Adler
  zero, but only (18) also has the hidden zeros", identified as the **L0 operator** (Bijnens–Kampf–Sjö conventions);
  its 4-point is A₄⁽⁴⁾ = s13² (eq. 19). **So "hidden zeros fix the O(p⁴) single-trace direction" is published (2024).**
  No data comparison there. Kampf's KEK talk (conference-indico.kek.jp/event/273, contribution 5483) says "the key

- **Albert & Rastelli arXiv:2203.11950**: large-N ordered amplitude M(s,u) = g1,0(s+u) + g2,0(s²+u²) + 2g2,1 su + …
  (3.4); map to LECs (4.26)–(4.27): g1,0 = 1/(2fπ²), g2,0 = (2L′3+4L′4)/fπ⁴ = (2ℓ1+3ℓ2)/(2fπ⁴), g2,1 = 4L′4/fπ⁴ =
  ℓ2/fπ⁴; SU(3) renaming (4.21) L1 = L′1 + L′4/2, L2 = L′2 + L′4, L3 = L′3 − 2L′4; at large N, L′1 = L′2 = 0. Sum rules
  (4.35): g2,0 = ⟨1/m⁴⟩, g2,0 − g2,1 = ⟨(−1)^J/m⁴⟩; bounds 0 ≤ g̃2′ ≤ 4g̃2 (ℓ2 ≥ 0, ℓ1+ℓ2 ≥ 0). **LS sits at
  g̃2 = −(γ+ψ(1/2))/2 ≈ 0.693147, g̃2′ = 2g̃2** (4.33), i.e. g2,1 = g2,0. Skyrme line g̃2′ = 4g̃2; data (Table 1, at
  μ = m_ρ) cluster near it. [CITED]

- **Pich, hep-ph/9502366** (review): chiral-quark-model/ENJL leading terms 8L1 = 4L2 = N_c/(48π²), L3 = −N_c/(96π²),
  i.e. also L3 = −2L2; VMD resonance saturation (Ecker et al. 1989) gives L2 = 2L1, L3 = −6L1 = −3L2. [CITED]

**What large N_c and chiral symmetry give by themselves (not claimed):** 2L1 = L2 (single-trace only; equivalently
L′1 = L′2 = 0); at large N there is no running. The *ratio* L3/L2 (equivalently g2,1/g2,0) is **not** fixed by chiral
symmetry + large N_c: it is the one free direction at O(p⁴). VMD gives −3, the chiral quark model −2, scalar-only
exchange g2,1 = 0 (L3/L2 → −∞ in the sense L′4 = 0).

**Conclusion of the sweep.** The geometry chain (c-preserving deformations of Tr φ³ ⇒ hidden zeros) fixes exactly
one O(p⁴) ratio, through the 4-point hidden zero at X13 + X24 = 0 (t = 0): **g2,1/g2,0 = 1 ⇔ L3/L2 = −2 ⇔ ℓ1/ℓ2 = −1/2.**
It does so with zero tuned parameters and independently of a = α′δ, α′ and F. It is **already published**
(Polyakov–Vereshagin 1996 for LS; Bartsch et al. 2024 for hidden zeros; also the chiral-quark-model relation).
**This rung is therefore labelled a REPRODUCTION + modern data test, not a new prediction.** What may be new
(to be checked in the review, not claimed now): (i) the statement that *every* completion in our chain (field-theory
δ-shift, [H]'s stringy δ-family for all a, LS, abelian Z) lands on the same ray, because of one structural fact
(the 4-point hidden zero); (ii) the sum-rule reading ⟨(−1)^J/m⁴⟩ = 0 (equal even/odd-spin weight); (iii) the C-odd
O(p⁴) piece of [H]'s non-cyclic completion; (iv) the comparison with BE14 that PV's footnote 4 asked for; (v) Lean.

## 1. Conventions

- Ordered large-N amplitude M(s,u), s ↔ u symmetric, no t-channel poles (AR 2.2); expansion (AR 3.4).
  In [H]'s variables X13 ↔ s, X24 ↔ u (up to an overall sign of s, u, which drops out of every ratio below).
- SU(3) L_i^r at μ = 0.77 GeV (BE14 convention); SU(2) ℓ_i^r(μ) = γ_i/(32π²)(ℓ̄_i + ln(Mπ²/μ²)), γ1 = 1/3,
  γ2 = 2/3, Mπ = 139.57 MeV (charged; CGL App. and §3).
- Large-N map (AR 4.21, 4.26, 4.27) as quoted above.

## 2. The completion (an input, stated precisely)

**Primary completion class 𝒞:** any ordered 4-point amplitude A(X13, X24) of the form (X13 + X24)·G(X13, X24) with
G analytic at 0 (the 4-point hidden zero holds to all orders), Bose/cyclic symmetrised if needed. Members we will
compute explicitly:

- (C1) [H]'s stringy δ-family (7.10), a = α′δ ∈ (0,1), and its cyclic (C-even) projection.
- (C2) Lovelace–Shapiro (AR 2.22).
- (C3) The field-theory δ-shift of Tr φ³ (M2d), 1/δ expansion.
- (C4) Abelian Z-theory (cited only; its O(p⁴) is zero).

The choice of completion *class* is the input; within it there are no free parameters for the target ratio.

## 3. Targets and pre-registered expectations

**Primary (T1).** R3 ≡ L3^r/L2^r at μ = 0.77 GeV. **Prediction: R3 = −2 exactly** (large N_c).
Data: **BE14 preferred NNLO fit, Bijnens & Ecker, Ann. Rev. Nucl. Part. Sci. 64 (2014) 149, arXiv:1405.6488,
Table 3, column "BE14"**: L2^r, L3^r with their quoted errors (which exclude higher-order errors), combined as
uncorrelated Gaussians (no correlation matrix is given).

**Tolerance (T1).** Theory band ±30% for O(1/N_c) corrections: R3 ∈ [−2.6, −1.4]. Justification: 1/N_c ≈ 1/3,
and BE14's own large-N_c test L_A = 2L1 − L2 is ≈ 30% of L2. No extra scale band: L3 does not run at one loop, and
L2's running is shown (secondary S5) but the verdict is at μ = 0.77 GeV.

**Verdict rule (T1).** Let I₁ = [R̂ − σ, R̂ + σ], I₂ = [R̂ − 2σ, R̂ + 2σ] (data, linear error propagation; an MC
check must agree).
- **PASS** if [−2.6, −1.4] ∩ I₁ ≠ ∅.
- **FAIL (kill outcome)** if [−2.6, −1.4] ∩ I₂ = ∅. Recorded as a miss; the target is not moved.
- **INCONCLUSIVE** otherwise.
- Discrimination note (not a verdict input): report where VMD (−3) and the chiral-quark-model/LS value (−2) sit.

**Secondary (do not change the verdict):**

  ℓ̄2 = 4.3 ± 0.1), prediction −1/2, same ±30% band and same rule. Also g̃2′/g̃2 = 2 (prediction) from it.

**Lean deliverables (pre-registered).**
- L1 (hidden zero ⇔ ratio): for the O(p⁴) polynomial P(s,u) = g20(s²+u²) + 2g21 su, (∀s, P(s,−s) = 0) ⇔ g21 = g20,
  and then P = g20(s+u)².
- L2 (completion structure): if A = (x+y)(c0 + c1x + c2y + …) then the symmetrised quadratic part is ((c1+c2)/2)(x+y)²
  (i.e. g21 = g20) for any c1, c2; C-odd part ((c1−c2)/2)(x²−y²).
- L3 (map to LECs): with AR (4.21, 4.26, 4.27) and L′1 = L′2 = 0: g21 = g20 ⇔ L′3 = 0 ⇔ L3 = −2L2 (with 2L1 = L2),
  and ⇔ 2ℓ1 + ℓ2 = 0.
- L4 (positivity consistency, reusing `Hankel.lean`-style discrete measures): with g20 = Σ w/m⁴, g20 − g21 =
  Σ w(−1)^J/m⁴, w ≥ 0: hidden zero ⇔ even-J and odd-J weights balance, and then 0 ≤ g21 ≤ 2g20 holds.
- L5 (LS numbers): the forward Hankel inequality for the LS coefficients, with π and log 2 bounded by Mathlib lemmas.
- L6 (data arithmetic): the BE14 central ratio and the interval check, exactly in ℚ.
