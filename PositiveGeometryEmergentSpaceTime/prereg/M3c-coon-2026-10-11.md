# M3c pre-registration: can the Coon q-deformation move ε, and how far?

Date: 2026-10-11 (Europe/London). Written and pushed before any M3c script, Lean or number. **Scope: a mathematical
reach question.** No pion-data comparison in this rung.

## Question

Can a geometric deformation of our completion (Lovelace–Shapiro, LS, the M3 hidden-zero completion) move
ε = 1 − g2,1/g2,0 off 0 toward the ρ side (ε < 0), how far, and while staying unitary?

## Families (fixed now)

Units α′ = 1 (ratios are α′-independent). ε ≡ 1 − g2,1/g2,0, where M(s,u) = g0,0 + g1,0(s+u) + g2,0(s²+u²)
+ 2g2,1 su + O(3) (AR normalisation; the overall sign is fixed so that g1,0 > 0). For a meromorphic amplitude with
k_min = 1, this equals the M3b/LECRatio spectral definition ⟨(−1)^J/m⁴⟩/⟨1/m⁴⟩. g0,0 is a subtraction constant and
does not enter.

- **Primary F_B, the "Adler-compatible Coon":** C = 1 and α0 = [1/2]_q ≡ (1 − q^{1/2})/(1 − q) = 1/(1 + √q)
  (→ 1/2 at q = 1). Why this one: at s = u = 0, σ0 = τ0 = √q, so the n = 0 numerator στ − q vanishes. **M(0,0) = 0**
  (the Adler-type zero, no constant term), as a pion amplitude needs (M2d/M2f). The LS hidden zero α′(s+u) = 0 is
  replaced by the curve στ = q through the origin (a "q-deformed hidden zero"). Spectrum: α′m_n² = [n+1]_q − [1/2]_q.
- **Secondary F_A, the FPRS Coon:** C = 1, α0 = 1/2 (FPRS eq. 118). It has M(0,0) ≠ 0 for q < 1 (the zero curve
  misses the origin), so it is not an Adler-zero amplitude. Computed as the prior-art reproduction.
- **Tertiary (report only):** F_B and F_A with FPRS's polynomial-residue prefactor (eq. 121).

**Disclosure.** While choosing F_B I did a first-order hand expansion. In F_B, (στ − q) ∝ (s+u) − κ su with
κ = (1−q)/√q > 0, which suggests the su term pushes g2,1 *below* g2,0, i.e. ε > 0 (the scalar side), at least near
q = 1. This is unverified, and nothing else was computed. It is stated so that a "wrong-direction" result cannot be
called a surprise.

## Questions and what is computed

- (a) Does q ≠ 1 move ε off 0? (yes/no, per family)
- (b) The ε range over the unitary q window. The window is our own check: partial waves of the pole residues at
  levels n ≤ 8 and J ≤ 16 (D = 4 Legendre), q on a grid in (0, 1), compared with FPRS's statement for F_A.
- (c) Does it reach the ρ side ε ≤ −0.5, or all of [−1, 0]?
- (d) Hidden zero: is M(s, −s) ≡ 0 for q < 1? (exact structural check; 1/Γ(−α′(s+u)) at q = 1 is M3's)
- Also: dε/dq at q = 1 (sign), the forward Hankel bound g1,0 g3,0 ≥ g2,0² (M2b), and membership of (g2,0, g2,1) in
  R_full (0 ≤ g2,1 ≤ 2g2,0) and R_fam (g2,0 ≤ g2,1 ≤ 2g2,0) along each family.

Methods: mpmath at 30 digits; the infinite product is truncated at N with an analytic tail check; Taylor coefficients
by numerical differentiation (mpmath.diff), cross-checked by a finite-difference fit and by series at q → 1 (sympy).
Lean: the exact q = 1 hidden-zero identity reuse (M3), F_B's M(0,0) = 0 and the first-order structure of στ − q as
exact ring identities, and region membership for the computed values as rational inequalities on rounded numbers
(labelled arithmetic).

## Outcomes (fixed now)

- **KILL-geometry:** ε(q) = 0 for all q in both families, or every ε ≠ 0 point is non-unitary. Then the geometry
  cannot move ε, and M3b is only a fit.
- **WRONG-SIDE:** the primary F_B moves ε only to ε > 0 in its unitary window. Then the Adler-compatible
  q-deformation cannot reach ρ dominance. If F_A reaches ε < 0, report that the ρ-ward motion needs giving up the
  Adler zero (a constant term).
- **PARTIAL-RHO:** unitary ε < 0 is reached but min ε > −0.5.
- **RHO:** unitary ε ≤ −0.5 is reached. Report whether [−1, 0] is covered.
- If PARTIAL-RHO or RHO holds for F_B, M3b gets a geometric q-version (q likely still free), and the q-dependence
  of g̃f2²/g̃ρ² becomes a later prereg. **Is q fixed?** Nothing in our chain fixes q; it is a free dial unless a
  computation here shows otherwise.
- Not allowed: changing α0, C or the family after seeing ε(q). Any new variant gets its own labelled addendum.
