## 1. MR-1 gap: resolved (theory only) [SIMULATED, exact sympy]

AHRV's C.5 and C.7 values come from the **generalised** LS (C.1–C.2): the trajectory is forced through the
*physical* f2 (r = m_f2²/m_ρ² ≈ 2.7, their eq. 4.1), not α₀ = ½.
- At r = 2.7064 we get g_f2²/g_ρ² = 0.52867.
- AHRV give 0.52684, a 0.35 % residual difference, consistent with their slightly different eq. 4.1 masses.
- At r = 3 (standard LS) the ratio is exactly 1/2.

**So MR-1's 1/2 is correct for the standard LS, and the 5 % gap is a difference in model choice, not an error.**

## 2. Predictions (standard LS: α₀ = ½, α′ = 1/(2m_ρ²); AHRV 2.12 normalisation, with MR-1's corrected constants)

The residues are polynomials: with a = ½ − α′u + n (level n), Γ(a)/Γ(a − n − 1). Legendre coefficients (exact):

| Level | State | m²/m_ρ² | Ordered-residue Legendre coefficients | g²/g_ρ² |
|---|---|---|---|---|
| n = 0 | ρ (I = 1, J = 1) | 1 | −½ P0 − ½ P1 | 1 |
| n = 1 | f2 (I = 0, J = 2) | 3 | 0 · P0 − ¾ P1 − ¾ P2 | 1/2 |
| n = 2 | **ρ3 (I = 1, J = 3)** | 5 | −5/32 (P0 + P1) − 25/32 (P2 + P3) | **5/16 = 0.3125** |
| n = 3 | **f4 (I = 0, J = 4)** | 7 | −7/180 P0 − 91/240 P1 − 49/144 P2 − 343/480 (P3 + P4) | **49/240 = 0.20417** |

**Width conversion.** Γ_X(ππ) = κ_X · g_X² · m_X · σ_X^{2J+1}, with κ ∝ c_I/(2J+1), c₁ = 4 and c₀ = 6. Relative
to ρ:
- κ_f2 = 9/10 (MR-1);
- **κ_ρ3 = 3/7**;
- **κ_f4 = 1/2**.

**Data → R:**

R_X^data = [Γ_X · BR(X → ππ) / Γ_ρ] / [κ_X · (m_X/m_ρ) · σ_X^{2J+1} / σ_ρ³],  σ = √(1 − 4m_π²/m²), m_π = 139.57 MeV.

For ρ, use the MR-1 S1 values: m = 775.26 MeV, Γ = 147.4 ± 1.6 MeV.

**Secondaries (non-blind, no verdict):** m_ρ3²/m_ρ² = 5 and m_f4²/m_ρ² = 7.

## 3. Band (fixed now)

- **1/N_c:** ±30 %, the same as MR-1.
- **LS-specific allowance, rising with level:** 10 % (n = 1) → **20 % (n = 2, ρ3)** → **30 % (n = 3, f4)**.
- **Reason for the rise:** a level-n residue is a degree-n polynomial in the trajectory. Real trajectories are
  non-linear, and the n = 1 mass is already 10 % off. Fractional residue errors grow roughly linearly in n. In
  addition, AHRV note that unitarity holds only for r ≥ 3 and was checked numerically only (150 poles), so
  higher-level residues are less controlled.
- **Totals:** σ_th(ρ3) = 36 % × 0.3125 = 0.1125; σ_th(f4) = 42 % × 0.2042 = 0.0858.
- MR-1's observed +33 % offset is **not** used to shift predictions.

## 4. Convention budget

Each variant gives an R value; σ_conv is half the max−min spread.
- **V1 primary:** Breit–Wigner masses and widths with σ^{2J+1}.
- **V2:** σ¹ (no barrier).
- **V3:** Blatt–Weisskopf with R = 5 GeV⁻¹: σ^{2J} → B_J(Rq)/B_J(Rm/2). Standard B3, B4 (von Hippel–Quigg).
- **V4:** LS masses (m_X = √5 m_ρ or √7 m_ρ) in the kinematic factors.
- **V5:** pole masses and widths, if PDG lists them.

**Branching-ratio sources:** the PDG average/fit if given. Otherwise, the PDG-listed measurement with the smallest
error.

## 5. Sources, well-posedness, rules

**Sources (per state):**
- **S1:** PDG 2026 averages: mass, width, BR(ππ).
- **S2:** an independent analysis: the single most precise *individual* ππ partial-wave / production measurement
  listed by PDG for that state, using its own mass, width and BR. If none exists separately, S2 = PDG pole values
  (as in MR-1, not independent; declared).

**Step 0, well-posedness (per source and state):**
- (i) Γ/m < 0.25;
- (ii) BR(ππ) is measured, not only a limit, with relative error ≤ 50 %;
- (iii) R > 0.

If (ii) fails, that source/state is **INCONCLUSIVE (data)** and cannot give PASS or FAIL. This pre-declares the
handling of a poorly measured f4 branching ratio.

**Per source and state:**

z = (R^data − R^pred) / √(σ_th² + σ_data² + σ_conv²)

- **PASS** if |z| ≤ 2.
- **FAIL** if |z| > 3.
- **INCONCLUSIVE** otherwise.

**Per state:**
- PASS if all well-posed sources PASS;
- FAIL if all well-posed sources FAIL;
- otherwise INCONCLUSIVE.
- If only one well-posed source exists, the state is **at most "PASS (single source)"**.

**Overall MR-1b:**
- PASS if both states PASS;
- FAIL if either state FAILs;
- otherwise INCONCLUSIVE.

**Kill:** a FAIL records that LS's higher-level couplings miss beyond the level-dependent band. That would limit LS to
n ≤ 1.
